## Projetos em destaque

### [ReConstrói](https://github.com/raonesi/reconstroi)
Plataforma de reaproveitamento de materiais de construção que conecta doadores, construtoras, ONGs e famílias, acompanhando o ciclo do anúncio até a doação finalizada.
**API Spring Boot + JWT · Web em Next.js · Desktop em Java Swing · PostgreSQL com Flyway · Docker Compose**

### [Cadastro de Receitas](https://github.com/raonesi/cadastro-receitas-spring-boot)
CRUD web de receitas com validação de formulário e persistência em PostgreSQL.
**Spring Boot · Spring MVC · Thymeleaf · JPA/Hibernate**

### [Projeto Biblioteca](https://github.com/raonesi/Projeto_biblioteca)
Sistema web de gerenciamento de biblioteca com controle de usuários, livros, empréstimos e multas por atraso.
**Java Servlets · JSP · DAO · PostgreSQL**
